ROBY WEBSITE - BẢN CẬP NHẬT LOGO + HÌNH ẢNH + VIDEO

Bản này đã được cập nhật:
- Logo ROBY thật
- Ảnh cơ sở ROBY
- Ảnh flyer khóa học
- Ảnh voucher
- Video giới thiệu ROBY

CÁCH CẬP NHẬT GITHUB:
1. Giải nén file ZIP.
2. Vào repository GitHub của bạn.
3. Upload toàn bộ file và thư mục trong gói này:
   - index.html
   - CNAME
   - thư mục assets
4. Nếu GitHub hỏi Replace/Overwrite thì chọn thay thế file cũ.
5. Commit changes.
6. Chờ khoảng 1-3 phút để GitHub Pages cập nhật.
7. Mở lại https://robyedutech.info.vn
8. Nếu trình duyệt vẫn hiện bản cũ, nhấn Ctrl + F5.

Lưu ý:
- Bản này dùng 1 file index.html và thư mục assets để chứa ảnh/video.
- Không cần sửa DNS nữa.
